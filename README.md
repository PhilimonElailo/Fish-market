# SilverFin Market

A static fish market website for SilverFin Market, Lake Turkana, Kenya.

## Pages

- `index.html` - home page
- `products.html` - fish catalog
- `cart.html` - cart
- `checkout.html` - order page
- `admin.html` - protected stock management page

## Stack

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage
